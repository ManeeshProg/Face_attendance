# Face Recognition System

This system performs face recognition to mark attendance for multiple individuals.

## Setup

1. Install required dependencies:
    ```
    pip install -r requirements.txt
    ```

2. Train the system on a dataset of faces by running:
    ```
    python train.py
    ```

3. Test the system with a new image:
    ```
    python predict.py
    ```

4. The system will automatically detect and recognize faces and mark attendance.
